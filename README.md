# **قیمت‌چاپ (Gheymat Chap) — نسخه ۰.۱.۰**

ابزار ساده و رایگان برای ساخت برچسب قیمت محصولات و چاپ چندین برچسب روی کاغذ A4.

## **امکانات**

- افزودن، ویرایش و حذف محصولات
- تعیین قیمت، تعداد برچسب‌ها و واحد پول (تومان/دالر/افغانی)
- پشتیبانی از ارقام فارسی، عربی و لاتین
- پیش‌نمایش زنده برچسب‌ها
- دارای سه قالب: کلاسیک، تاریک و ساده
- ذخیره‌سازی خودکار اطلاعات در LocalStorage
- چاپ برچسب‌ها با استفاده از CSS Print روی کاغذ A4
- بدون نیاز به سرور، فریم‌ورک یا کتابخانه‌های اضافی

## **طریقه اجرا**

فایل `index.html` را در مرورگر باز کنید.

(برای آزمایش بهتر، می‌توانید از افزونه Live Server استفاده کنید.)

## **طریقه چاپ**

در پنجره چاپ مرورگر، تنظیمات زیر را انتخاب کنید:

- **Paper:** A4
- **Scale:** 100% / Actual size
- **Margins:** Default (حاشیه صفحه توسط CSS تنظیم شده است)
- **Background graphics:** در صورت استفاده از قالب تاریک، این گزینه را فعال کنید.

توجه: بعضی چاپگرها دارای حاشیه غیرقابل چاپ هستند؛ بنابراین برای اطمینان از اندازه دقیق برچسب‌ها، ابتدا یک چاپ آزمایشی انجام دهید.

## **راه‌اندازی در GitHub Pages**

1\. فایل‌های پروژه را به یک مخزن (Repository) در گیت‌هاب اضافه کنید.

2\. وارد بخش **Settings → Pages** شوید.

3\. در قسمت Branch، گزینه `main` و پوشه `/root` را انتخاب کنید.

4\. روی **Save** کلیک کنید.
